 Where your review instructions live in the repo. .gitar/review/ Copy 
 How to use it
 Install Gitar as a GitHub App on your hackathon repo and ship every feature as a pull request, so Gitar catches logic errors and bugs before you merge. Write your project's conventions as review instructions in .gitar/review/, add repository rules for repeatable workflow actions, and turn on auto-apply so Gitar diagnoses failing CI and pushes the fix. It all runs in the browser, so there's nothing to install locally. The free 14-day Gitar Pro trial needs no credit card and includes auto-apply and custom rules.
