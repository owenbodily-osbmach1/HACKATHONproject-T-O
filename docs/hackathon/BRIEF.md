## Eligibility and conduct

Main coding and design start after the event begins. Advance ideas, notes, sketches, research, and trying sponsor tools are allowed. Public frameworks, libraries, templates, APIs, tools, and assets are allowed; judging covers original work during the event. A previously completed project, duplication, or copying can disqualify an entry.

Publish source and a README with setup instructions. Disclose AI assistants. Both participants must understand and explain their code and architecture, verify the work, and contribute meaningfully. Use authorized data/accounts; exclude private information and credentials from source and demos. Team members keep project IP and should agree on ownership before submission. Respect participants; no harassment, spam, sabotage, plagiarism, or judging manipulation. Organizers decide eligibility and judging.
